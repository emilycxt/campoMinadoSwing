# Jogo Campo Minado em Java

![Java](https://img.shields.io/badge/Java-12-ED8B00?logo=java&logoColor=white)
![GUI](https://img.shields.io/badge/GUI-Swing-blue)

Um clássico jogo de Campo Minado desenvolvido em **Java 12** utilizando **Swing** para a interface gráfica.

Este projeto foi desenvolvido sob orientação de videoaulas do curso Java ministrado por **Leonardo Moura Leitao**.

## 📥 Download do Executável
[🟢 Baixar Campo Minado 1.1 (ZIP)](https://github.com/user-attachments/files/23124376/Campo.Minado.1.1.zip)

💡 **Observação:** Extraia o arquivo ZIP e execute o arquivo `.jar` dentro dele para jogar.

Versão Final com Dificuldades Disponíveis:
- **Fácil:** 9x9 com 10 minas  
- **Médio:** 16x16 com 40 minas  
- **Difícil:** 16x30 com 80 minas

### 📚 Habilidades técnicas desenvolvidas

![OOP](https://img.shields.io/badge/Object-Oriented-blue)
![Observer](https://img.shields.io/badge/Observer%20Pattern-green)
![Swing](https://img.shields.io/badge/Swing-GUI-orange)
![Mouse Events](https://img.shields.io/badge/Mouse%20Events-purple)
![2D Arrays](https://img.shields.io/badge/2D%20Arrays-yellow)
![Game Logic](https://img.shields.io/badge/Game%20Logic-brown)
![Project Organization](https://img.shields.io/badge/Project%20Organization-red)

- **Programação orientada a objetos aplicada a jogos**: modelagem de elementos e lógica do jogo de forma modular e reutilizável.  
- **Implementação do padrão Observer**: comunicação eficiente entre componentes do jogo para atualização automática da interface.  
- **Desenvolvimento de interfaces gráficas com Swing**: criação de botões dinâmicos, atualização visual de elementos e estilização com cores e textos.  
- **Gerenciamento de eventos de mouse**: tratamento de cliques esquerdo/direito com diferentes comportamentos (abrir ou marcar campos).  
- **Trabalho com matrizes bidimensionais e lógica de vizinhança**: controle do tabuleiro, contagem de minas próximas e expansão automática de áreas seguras.  
- **Controle de fluxo e lógica de jogo**: definição de condições de vitória/derrota e gerenciamento do estado do jogo.  
- **Boas práticas de organização e versionamento**: estruturação de projeto e clareza na separação de responsabilidades.
